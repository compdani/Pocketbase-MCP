# Design history

The documents the module was designed from. They are kept for background and
are **not** kept up to date: where they differ from the code, the current
docs in [docs/](..) win.

| Document | What it was |
|---|---|
| [integration-review.md](integration-review.md) | The first survey (2026-11) of how customjs, list_pocket, dreia_pocket and the pb-postgress fork integrate MCP with PocketBase today, with a proposed package shape. |
| [integration-review-assessment.md](integration-review-assessment.md) | A review of that survey: the full-session-reuse decision and the gaps to resolve before building. |
| [server-module-plan.md](server-module-plan.md) | The MCP server plan and milestones, with "As built" notes added up to milestone 5. Also has source anchors into customjs and the fork. Replaced by [mcp-server.md](../mcp-server.md). |
| [chat-interface-plan.md](chat-interface-plan.md) | The chat plan, including evidence from the List Pocket, Event Pocket and Static Dealmakers assistants and the host editor-adapter design. Replaced by [chat.md](../chat.md). |

Test evidence for each milestone is in [verification/](../../verification).
